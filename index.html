Local AI

Local AI Workstation

Setup, serving and daily use

I install, tune, serve and use AI systems on my own hardware from start to finish: language models, image generation, 3D generation and agent tooling. The setup is used actively for coding assistance, automation and content pipelines.

What I do

  • Run large open models locally, for example a 35-billion-parameter mixture-of-experts model at about 54 tokens per second using hybrid GPU and CPU offload
  • Serve models through local OpenAI-compatible endpoints and connect coding agents and MCP tools to them
  • Build AI-assisted Unreal Engine workflows with an editor bridge, reusable skills, a retrieval index and CI validation
  • Run Strata, an open-source local inference engine, with custom setups for Qwen3.8-Flash-Next and DeepSeek V4.1-Flash, streaming the very large DeepSeek model from SSD
  • Serve smaller models such as Nanbeige 4.2 3B through a custom OpenAI-compatible server built with Transformers and FastAPI
  • Download, convert and verify models from Hugging Face, including GGUF quantizations and checksum checks
